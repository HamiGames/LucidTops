LucidTops Docker build commands

Host: Raspberry Pi 5 via SSH
Origin directory (mandatory): cd /mnt/myssd/LucidTops
Platform: linux/arm64

No GIT pull. All operational values from hardware pull → secrets at time of operation.
PaySystems/Pay.dockerfile is OUT OF SCOPE for this document.

==============================================================================
0. SHARED OPERATION SEQUENCE (every container)
==============================================================================

A) Origin
  cd /mnt/myssd/LucidTops

B) §16.7 Rebuild wipe (run when the image already exists)
  IMAGE_TAG=<tag for this container>
  CONTAINER_NAME=<runtime name if any>
  docker ps -aq --filter ancestor="${IMAGE_TAG}" | xargs -r docker stop
  docker ps -aq --filter ancestor="${IMAGE_TAG}" | xargs -r docker rm
  docker images -q "${IMAGE_TAG}" | xargs -r docker rmi -f
  # Wipe generated volumes/content for that service (paths come from that
  # container's secrets / SECRETS_DIR — do not hardcode volume IDs here).

C) Hardware pull (time of operation)
  Run the folder's pull script (see each section). Confirm:
    /mnt/myssd/LucidTops/<directory>/secrets/*.secrets
  exists and contains IP/MAC/DockerDNS/network names written by pull.

D) §16.4 Docker networks
  # Read network name from the secrets file written by pull (example key name
  # DOCKER_NETWORK_NAME — actual key is whatever that folder's secrets writer uses).
  NETWORK_NAME=$(grep -E '^DOCKER_NETWORK_NAME=' /mnt/myssd/LucidTops/<directory>/secrets/*.secrets | head -1 | cut -d= -f2-)
  docker network inspect "${NETWORK_NAME}" >/dev/null 2>&1 \
    || docker network create "${NETWORK_NAME}"

E) Build
  Always: --no-cache --platform linux/arm64 -f <dockerfile> -t <tag> /mnt/myssd/LucidTops

F) Run
  Bind-mount secrets + LucidTops SSD; attach --network from secrets (NETWORK_NAME above).
  Do not bake IP/MAC/ports/onion into the image.

1. backend — Server.dockerfile
==============================================================================
Image tag: lucid-server-default:v1.0.0
Secrets:   /mnt/myssd/LucidTops/backend/secrets
Pull:      python3 /mnt/myssd/LucidTops/backend/pull_information.py

Wipe then:
  docker build --no-cache --platform linux/arm64 \
    -f /mnt/myssd/LucidTops/backend/Server.dockerfile \
    -t lucid-server-default:v1.0.0 \
    /mnt/myssd/LucidTops

Run (network + mounts from secrets at operation):
  NETWORK_NAME=$(grep -E '^DOCKER_NETWORK_NAME=' /mnt/myssd/LucidTops/backend/secrets/*.secrets | head -1 | cut -d= -f2-)
  docker run -d --name lucid-server-default \
    --network "${NETWORK_NAME}" \
    -v /mnt/myssd/LucidTops:/mnt/myssd/LucidTops \
    -v /mnt/myssd/LucidTops/backend/secrets:/mnt/myssd/LucidTops/backend/secrets \
    -e SECRETS_DIR=/mnt/myssd/LucidTops/backend/secrets \
    -e LUCID_TOPS_ROOT=/mnt/myssd/LucidTops \
    lucid-server-default:v1.0.0

4. proxy — proxy.dockerfile
==============================================================================
Image tag: lucid-proxy:v1.0.0
Secrets:   /mnt/myssd/LucidTops/proxy/secrets
Pull:      python3 /mnt/myssd/LucidTops/proxy/Bootstrap.py
           (Bootstrap.pull_information writes proxy.secrets / Master.secrets)

Build-args (required at time of operation — no Dockerfile defaults for BASE_IMAGE):
  # Resolve from hardware pull / Bootstrap output into the shell before build:
  #   BASE_IMAGE=...     # real base image available on this Pi
  #   APT_PACKAGES=...   # OS packages required on this hardware (space-separated)
  # Optional: PIP_PACKAGES=...

  docker build --no-cache --platform linux/arm64 \
    -f /mnt/myssd/LucidTops/proxy/proxy.dockerfile \
    --build-arg BASE_IMAGE="${BASE_IMAGE}" \
    --build-arg APT_PACKAGES="${APT_PACKAGES}" \
    -t lucid-proxy:v1.0.0 \
    /mnt/myssd/LucidTops

  NETWORK_NAME=$(grep -E '^DOCKER_NETWORK_NAME=' /mnt/myssd/LucidTops/proxy/secrets/*.secrets | head -1 | cut -d= -f2-)
  docker run -d --name lucid-proxy \
    --network "${NETWORK_NAME}" \

    -v /mnt/myssd/LucidTops/proxy/secrets:/mnt/myssd/LucidTops/proxy/secrets \
